BATIK ADINATA - WEBSITE 6 HALAMAN

Isi folder:
- index.html: Home
- about.html: About
- shop.html: Shop / Produk
- gallery.html: Gallery
- blog.html: Blog
- contact.html: Contact
- style.css: desain seluruh halaman
- images/: foto visual yang sudah dipasang ke dalam HTML

CARA MEMBUKA:
1. Extract ZIP.
2. Buka folder ini di VS Code (File > Open Folder).
3. Klik index.html dan jalankan dengan Live Server atau browser.
4. Semua halaman saling terhubung lewat menu navigasi.

CATATAN:
Gambar sudah dipasang langsung di kode HTML melalui folder images. Kamu bisa mengganti file gambar dengan foto produk sendiri menggunakan nama file yang sama. Teks, harga, alamat, dan kontak masih contoh dan perlu disesuaikan. Form kontak masih demo, belum mengirim pesan ke server.
